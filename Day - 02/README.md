# Day 02 - Build Flask Application

## Objective

Build a simple Flask application that will be used throughout this DevSecOps project.

## Features

- Home Page
- Health Check Endpoint
- JSON API Endpoint

## Run Locally

python3 -m venv venv

source venv/bin/activate

pip install -r app/requirements.txt

python app/app.py

Open

http://localhost:5000

Health Endpoint

http://localhost:5000/health

API Endpoint

http://localhost:5000/api
