# Day 07 - Docker Volumes & Bind Mounts

## Objective

Learn how Docker stores data and how to make data persistent using
Docker Volumes and Bind Mounts.

## Topics

- Named Volumes
- Anonymous Volumes
- Bind Mounts
- Persistent Storage
- Volume Lifecycle
- Data Backup

## Learning Outcome

After completing this lab you will understand how containers keep
their data even after they are removed.
