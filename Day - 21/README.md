# Day 21 - OWASP Dependency-Check

## Objective

Learn how to scan project dependencies for known
vulnerabilities using OWASP Dependency-Check.

## Topics Covered

- Software Composition Analysis (SCA)
- Dependency Scanning
- CVE Detection
- CVSS Scoring
- HTML & JSON Reports
- Jenkins Integration
- DevSecOps

## Learning Outcome

Detect vulnerable third-party libraries before
deploying applications.
