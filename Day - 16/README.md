# Day 16 - Nexus Repository Manager

## Objective

Learn how to use Nexus Repository Manager
to store and manage build artifacts
generated by Jenkins pipelines.

## Topics Covered

- Nexus Repository Manager
- Artifact Repository
- Hosted Repository
- Proxy Repository
- Group Repository
- Docker Registry
- Maven Repository
- Jenkins Integration

## Learning Outcome

Build a CI pipeline that publishes
artifacts to Nexus before deployment.
