# Day 23 - Cosign Container Image Signing

## Objective

Learn how to sign and verify Docker container images
using Cosign and Sigstore.

## Topics Covered

- Cosign
- Sigstore
- Image Signing
- Image Verification
- Public & Private Keys
- Supply Chain Security
- Jenkins Integration

## Learning Outcome

Automatically sign container images in CI/CD and
verify them before deployment.
