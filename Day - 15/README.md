# Day 15 - SonarQube Static Code Analysis

## Objective

Learn how to integrate SonarQube into a Jenkins CI pipeline
to perform static code analysis before deployment.

## Topics Covered

- SonarQube
- Static Code Analysis
- Code Smells
- Bugs
- Vulnerabilities
- Security Hotspots
- Quality Gates
- Jenkins Integration

## Learning Outcome

Create a CI pipeline that automatically analyzes source code
quality before Docker image creation.
