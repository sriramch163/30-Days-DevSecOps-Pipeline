# Day 18 - Trivy Container Image Security Scanning

## Objective

Learn how to scan Docker images using Trivy
to detect vulnerabilities before deployment.

## Topics Covered

- Trivy
- CVE
- Vulnerability Scanning
- Severity Levels
- OS Packages
- Application Dependencies
- Security Reports
- Jenkins Integration

## Learning Outcome

Build a secure CI pipeline that scans container
images before pushing them to a registry.
