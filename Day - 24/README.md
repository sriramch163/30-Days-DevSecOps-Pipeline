# Day 24 - Kyverno Kubernetes Policy Engine

## Objective

Learn how to secure Kubernetes clusters using
Kyverno by enforcing admission policies.

## Topics Covered

- Kyverno
- Admission Controller
- ClusterPolicy
- Policy Enforcement
- Validation Rules
- Mutation Rules
- Image Verification
- Kubernetes Security

## Learning Outcome

Create Kubernetes security policies that validate
resources before they are deployed.
