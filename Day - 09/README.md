# Day 09 - Docker Registry & Docker Hub

## Objective

Learn how Docker images are stored, versioned, shared and downloaded
using Docker Hub and Docker Registry.

## Topics Covered

- Docker Registry
- Docker Hub
- Image Tagging
- Docker Login
- Docker Push
- Docker Pull
- Versioning Strategy

## Learning Outcome

Understand how to publish and reuse Docker images in real-world CI/CD
pipelines.
