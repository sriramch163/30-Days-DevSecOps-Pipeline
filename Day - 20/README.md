# Day 20 - Grype Vulnerability Scanning

## Objective

Learn how to use Grype to scan Docker images and
Software Bill of Materials (SBOMs) for vulnerabilities.

## Topics Covered

- Grype
- CVE Detection
- Image Scanning
- SBOM Scanning
- Risk Assessment
- Security Reports
- Jenkins Integration
- DevSecOps Pipeline

## Learning Outcome

Generate vulnerability reports using Grype and
integrate them into Jenkins CI/CD pipelines.
