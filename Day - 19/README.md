# Day 19 - Syft Software Bill of Materials (SBOM)

## Objective

Learn how to generate a Software Bill of Materials (SBOM)
using Syft to improve software supply chain security.

## Topics Covered

- Syft
- SBOM
- SPDX
- CycloneDX
- Package Inventory
- Software Supply Chain
- Jenkins Integration
- Compliance

## Learning Outcome

Generate SBOM reports for Docker images and integrate
them into a Jenkins CI/CD pipeline.
