# Day 13 - Jenkins Credentials & Secret Management

## Objective

Learn how Jenkins securely stores and uses credentials
without exposing sensitive information inside pipelines.

## Topics Covered

- Jenkins Credentials
- Secret Text
- Username & Password
- SSH Private Keys
- Credentials Binding Plugin
- Environment Variables
- Secure Pipelines

## Learning Outcome

Build secure Jenkins pipelines that authenticate with
GitHub, Docker Hub and cloud providers without exposing secrets.
